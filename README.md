# Image-Oscillation-IV

p5.js と Web Audio API を用いた、オシロスコープ波形（リサジュー図形）の描画・発音・視覚化を行うためのビジュアライザー兼シンセサイザーのプロトタイプです。

---

## 概要

このWebアプリは、XY平面上にマウスやタッチ操作で自由な軌跡を描き、それを左右のスピーカーから出力される音声波形にリアルタイムに変換・発音しつつ、同時にオシロスコープ（XYスコープ）にリサジュー図形として再描画するシンセサイザー＆ビジュアライザーです。

### 主な機能

- **左右独立のステレオ・オシレーター**: 左チャンネル (L) と右チャンネル (R) に異なる波形を割り当て、ステレオ空間でリサジュー図形を形成。
- **XYプロット描画（カスタム波形入力）**: 画面中央のXY平面エリアをドラッグしてお絵描きすると、その軌跡が音声波形（L/Rの PeriodicWave）としてサンプリングされ、音色とオシロスコープの描画に反映されます。
- **波形エディター**: 画面下のパッドエリアで、左チャンネルの波形（Glitch適用前）を個別に微調整可能。
- **各種コントロールスライダー**:
  - **Freq (ベース周波数)**: 音の高さの基本周波数を制御。
  - **Ratio (周波数比率)**: 左右の周波数の比を変化させます。整数比に吸着する機能があり、比率に応じて複雑で美しいリサジュー図形（波形）が描かれます。
  - **Glitch (量子化)**: 波形のサンプル分解能（4〜64段階）を粗くし、デジタルなグリッチ音や粗い波形グラフィックを生成します。
- **オクターブ切替 & 鍵盤演奏**:
  - 画面最下部の円形鍵盤をクリックするか、PCキーボード（`A`, `W`, `S`, `E`, `D`, `F`, `T`, `G`, `Y`, `H`, `U`, `J`）で演奏可能です。
  - `+` / `-` ボタンまたはキーボードの `;` / `-` キーでオクターブを切替可能。
  - 複数音を押さえた場合は自動でアルペジエーター（固定テンポ）が動作します。

## 実行方法

本アプリは、Web Audio API や p5.js (p5.sound) の動作にセキュリティ上のローカルサーバー環境が必須となります。

### 前提条件

- [Node.js (npm)](https://nodejs.org/) がインストールされていること。

### 起動手順

1. **プロジェクトフォルダへの移動**
   ターミナル（PowerShellやCommand Promptなど）を開き、プロジェクトのルートディレクトリに移動します。
   ```bash
   cd Image-Oscillation-IV
   ```

2. **依存関係のインストール**
   以下のコマンドを実行し、簡易Webサーバー (`http-server`) をインストールします。
   ```bash
   npm install
   ```

3. **ローカルサーバーの起動**
   以下のコマンドで開発用ローカルサーバーを起動します。
   ```bash
   npm run dev
   # または
   npm start
   ```
   *※起動後、自動的にブラウザ（通常は `http://localhost:8000`）が開きます。*

### その他の実行方法 (Node.js を使わない場合)

VS Code の **Live Server** 拡張機能を利用するか、Pythonがインストールされている場合はターミナルで `python -m http.server 8000` を実行し、ブラウザで `http://localhost:8000` にアクセスすることでも起動可能です。

## 基本操作のポイント

1. **音声出力の有効化**
   ブラウザのセキュリティ仕様により、起動直後はミュート状態になっています。**画面内の任意の場所をクリックまたはタップ**するとオーディオエンジンが有効になり、音が鳴り始めます。
2. **描画と音の変化**
   画面中央の大きな正方形（XYプロット領域）をドラッグして円やらせん、星型などを描いてみてください。描いた図形によって音色が劇的に変化し、その描画がそのままオシロスコープに反映されます。
3. **キーボードによる演奏**
   キーボード（A, W, S, E...）で音階を演奏したり、比率（Ratio）を変えながらグリッチ（Glitch）スライダーを動かして、直感的なサウンドメイクと映像の変化を楽しめます。
